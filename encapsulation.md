---

Инкапсуляция — один из основных принципов объектно-ориентированного программирования, заключающийся в объединении данных и методов работы с ними внутри одного объекта, а также в ограничении прямого доступа к внутреннему состоянию объекта.

Главная цель инкапсуляции — защита данных от некорректного изменения и сокрытие внутренней реализации объекта от внешнего кода. Вместо прямого доступа к полям объекта предоставляются специальные методы для получения и изменения данных.

В классических объектно-ориентированных языках программирования используются модификаторы доступа (`private`, `protected`, `public`), которые позволяют ограничивать доступ к данным класса.

В Python инкапсуляция реализована несколько иначе:

- `_attribute` — соглашение о «защищённом» атрибуте;
- `__attribute` — механизм name mangling для ограничения прямого доступа;
- `@property` — позволяет управлять доступом к данным через геттеры и сеттеры;
- отсутствуют строгие модификаторы доступа, как в Java или C++;
- инкапсуляция в Python основана на соглашениях между разработчиками.

## Ключевые особенности инкапсуляции в Python

1. Простая реализация через соглашения об именовании.
2. Поддержка скрытия данных через двойное подчёркивание.
3. Возможность контроля доступа через `property`.
4. Гибкость по сравнению со строго типизированными языками.
5. Удобство расширения и переопределения поведения объектов.

## Пример инкапсуляции на Python

```python
class BankAccount:
    def __init__(self, owner: str, balance: float):
        self.owner = owner
        self.__balance = balance

    @property
    def balance(self) -> float:
        return self.__balance

    def deposit(self, amount: float) -> None:
        if amount > 0:
            self.__balance += amount

    def withdraw(self, amount: float) -> None:
        if 0 < amount <= self.__balance:
            self.__balance -= amount
        else:
            print("Недостаточно средств")


account = BankAccount("Алексей", 1000)

print(account.balance)

account.deposit(500)
print(account.balance)

account.withdraw(300)
print(account.balance)
```

В данном примере поле `__balance` скрыто от прямого доступа извне. Изменение значения возможно только через методы `deposit()` и `withdraw()`, что обеспечивает контроль над состоянием объекта.
