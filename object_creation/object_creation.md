# Создание объектов

**Автор:** Махов Владислав

**Концепция:** Создание объектов

**Язык основного примера:** Python

---

Создание объекта — это процесс, при котором из описания класса появляется конкретный экземпляр с собственными данными. В Python для этого определяют метод `__init__`: он вызывается автоматически при вызове `ClassName(...)` и задаёт начальные значения атрибутов.

Иногда один конструктор неудобен: объект хочется создать из строки, из кортежа или получить заранее известный «стандартный» экземпляр. Для таких случаев используют **фабричные конструкторы** — методы класса с декоратором `@classmethod`. Они принимают `cls` вместо `self` и возвращают новый объект через `cls(...)`.

В Python основные способы создания объектов:

- `__init__` — стандартный конструктор, задаёт начальные атрибуты;
- `@classmethod` — фабричные конструкторы, создающие объект из другого формата данных;
- Именованные конструкторы — частный случай `@classmethod` с понятным именем (`origin`, `from_string` и т. д.).

## Сравнение способов создания объектов в Python

| Способ | Декоратор | Первый аргумент | Назначение |
|---|---|---|---|
| `__init__` | — | `self` | Задаёт атрибуты при создании объекта |
| Фабричный конструктор | `@classmethod` | `cls` | Создаёт объект из другого формата данных |
| Именованный конструктор | `@classmethod` | `cls` | Создаёт частный случай объекта (`origin`, `zero` и т. д.) |

## Ключевые особенности

1. `__init__` не создаёт объект — он только **заполняет** его атрибуты. Python создаёт «пустой» объект сам, до вызова `__init__`.
2. `@classmethod`-конструкторы всегда возвращают `cls(...)` — это позволяет использовать их и в дочерних классах.
3. Все способы создают объект одного типа — `type(obj) is Point`.
4. Именованные конструкторы делают код понятнее: `Point.origin()` читается лучше, чем `Point(0, 0)`.

## Когда использовать фабричные конструкторы?

- Объект можно создать из разных форматов данных (строка, файл, кортеж).
- Хочется спрятать логику разбора внутри класса, а не писать её снаружи каждый раз.
- Нужен «говорящий» способ создать типичный объект (`Point.origin()`, `Color.white()` и т. д.).

## Пример создания объектов на Python

В примере ниже создаётся класс `Point` для точки на плоскости.
Показаны стандартный конструктор и три фабричных метода.

```python
class Point:
    """Точка на плоскости с координатами x и y."""

    def __init__(self, x: float, y: float) -> None:
        self.x = x
        self.y = y

    @classmethod
    def from_tuple(cls, coords: tuple) -> "Point":
        """Создать точку из кортежа (x, y)."""
        return cls(coords[0], coords[1])

    @classmethod
    def from_string(cls, s: str) -> "Point":
        """Создать точку из строки формата 'x,y'."""
        x, y = map(float, s.split(","))
        return cls(x, y)

    @classmethod
    def origin(cls) -> "Point":
        """Создать точку в начале координат (0, 0)."""
        return cls(0.0, 0.0)

    def distance_to(self, other: "Point") -> float:
        """Расстояние до другой точки."""
        return ((self.x - other.x) ** 2 + (self.y - other.y) ** 2) ** 0.5

    def __repr__(self) -> str:
        return f"Point({self.x}, {self.y})"

    def __eq__(self, other: object) -> bool:
        if not isinstance(other, Point):
            return False
        return self.x == other.x and self.y == other.y


# ── Стандартный конструктор ─────────────────────────────────────────────────

p1 = Point(3.0, 4.0)
print(p1)                       # Point(3.0, 4.0)

# ── Фабричные конструкторы ──────────────────────────────────────────────────

p2 = Point.from_tuple((1.0, 2.0))
print(p2)                       # Point(1.0, 2.0)

p3 = Point.from_string("5.0,7.5")
print(p3)                       # Point(5.0, 7.5)

p4 = Point.origin()
print(p4)                       # Point(0.0, 0.0)

# ── Использование ───────────────────────────────────────────────────────────

print(p1.distance_to(p4))       # 5.0  (3² + 4² = 5²)
print(p1 == Point(3.0, 4.0))    # True
print(p1 == p2)                 # False
```

**Вывод программы:**
```
Point(3.0, 4.0)
Point(1.0, 2.0)
Point(5.0, 7.5)
Point(0.0, 0.0)
5.0
True
False
```
