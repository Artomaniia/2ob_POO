## Что такое объект?

Объект — это экземпляр класса. Класс — это чертёж, а объект — конкретный экземпляр, созданный по этому чертежу.

## Синтаксис создания объекта в Python

```python
class Car:
    def __init__(self, brand):
        self.brand = brand

my_car = Car("Toyota")
