# Аксессоры (Getters, Setters, Deleters)

**Автор:** Тоголмачева Полина, 2об_POO

## Определение

**Аксессоры** — это специальные методы класса, которые позволяют контролировать доступ к атрибутам (свойствам) объекта. Они используются для:

- **Getter** (геттер) — получение значения атрибута.
- **Setter** (сеттер) — установка значения атрибута.
- **Deleter** (делетер) — удаление атрибута.

Основная цель аксессоров — **инкапсуляция** и контроль над данными: проверка значений, вычисления «на лету», логирование, ленивая инициализация и т.д.

---

## Особенности в Python

Python предоставляет удобный синтаксический сахар через декоратор **`@property`**. Это позволяет обращаться к методам как к обычным атрибутам, сохраняя при этом контроль.


**Ключевые особенности Python:**

- `@property` превращает метод в «виртуальный атрибут».
- Поддержка **deleter** (`@attr.deleter`) — редкая возможность в языках.
- Можно определить только getter (тогда атрибут только для чтения).
- Работает с **дескрипторами** под капотом.
- Поддерживает **type hints** и IDE-подсказки.

-----

## Реализация в C 

В чистом C нет встроенных аксессоров. Их имитируют **функциями** и **указателями на структуры**. Доступ к полям структуры контролируется через getter/setter-функции.


**Ключевые особенности C:**

- Всё реализуется вручную через функции.
- Нет автоматического синтаксиса — нужно всегда вызывать `user_get_name(user)`.
- Требуется ручное управление памятью (`strdup`, `free`).
- Нет встроенной валидации на уровне языка — вся логика в функциях.

---

## Когда использовать аксессоры

- **Необходима валидация** данных при установке.
- Нужно вычислять значение динамически (например, `full_name` из `first_name` + `last_name`).
- Требуется логирование доступа.
- Хотите сделать атрибут **только для чтения** (только getter).
- Нужно выполнить действие при удалении атрибута (deleter).

**Преимущества:**
- Контроль над состоянием объекта.
- Сокрытие внутренней реализации.
- Упрощение рефакторинга (можно изменить внутреннее хранение без изменения публичного API).
