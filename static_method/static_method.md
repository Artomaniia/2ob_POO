**Язык основного примера:** Python

---

Статический метод — это метод класса, который не привязан ни к экземпляру класса, ни к самому классу. Он не принимает автоматически первый аргумент `self` (как обычные методы) или `cls` (как методы класса). Статические методы работают как обычные функции, но находятся в пространстве имён класса.

Главная цель статических методов — логически сгруппировать вспомогательные функции внутри класса, когда эти функции связаны с классом по смыслу, но не нуждаются в доступе к его состоянию или атрибутам.

В Python статический метод объявляется с помощью декоратора `@staticmethod`. В других языках, например в C, аналогичное поведение достигается через обычные функции, сгруппированные по соглашению именования.

В Python статические методы:

- `@staticmethod` — объявляет метод статическим;
- не получают автоматически `self` или `cls`;
- вызываются как через экземпляр, так и через имя класса;
- не могут изменять состояние экземпляра или класса напрямую;
- используются для утилитарных/вспомогательных операций.

## Сравнение видов методов в Python

| Вид метода | Декоратор | Первый аргумент | Доступ к объекту | Доступ к классу |
|---|---|---|---|---|
| Обычный метод | — | `self` | ✅ Да | ✅ Через `self.__class__` |
| Метод класса | `@classmethod` | `cls` | ❌ Нет | ✅ Да |
| Статический метод | `@staticmethod` | — | ❌ Нет | ❌ Нет |

## Ключевые особенности статических методов в Python

1. Объявляются с декоратором `@staticmethod`.
2. Не имеют доступа к атрибутам экземпляра (`self`) или класса (`cls`).
3. Вызываются через имя класса: `ClassName.method()`.
4. Могут быть вызваны и через экземпляр: `obj.method()`.
5. Используются для группировки вспомогательной логики в классе.
6. Не зависят от состояния объекта — всегда дают одинаковый результат при одинаковых аргументах.

## Когда использовать статический метод?

Статический метод следует использовать, когда:
- функция логически относится к классу, но не использует `self` или `cls`;
- нужна утилитарная функция (валидация, конвертация, математика);
- хочется избежать вынесения функции за пределы класса, сохраняя читаемость кода.

## Пример статического метода на Python

В примере ниже создаётся класс `TemperatureConverter` для конвертации температур.
Все методы — статические, так как не зависят от состояния объекта.

```python
class TemperatureConverter:
    """
    Класс для конвертации температур между различными шкалами.

    Демонстрирует использование статических методов:
    ни один метод не использует self или cls,
    все методы работают только с переданными аргументами.
    """

    @staticmethod
    def celsius_to_fahrenheit(celsius: float) -> float:
        """Перевод из Цельсия в Фаренгейт."""
        return celsius * 9 / 5 + 32

    @staticmethod
    def fahrenheit_to_celsius(fahrenheit: float) -> float:
        """Перевод из Фаренгейта в Цельсий."""
        return (fahrenheit - 32) * 5 / 9

    @staticmethod
    def celsius_to_kelvin(celsius: float) -> float:
        """Перевод из Цельсия в Кельвины."""
        return celsius + 273.15

    @staticmethod
    def kelvin_to_celsius(kelvin: float) -> float:
        """Перевод из Кельвинов в Цельсий."""
        return kelvin - 273.15

    @staticmethod
    def is_valid_kelvin(kelvin: float) -> bool:
        """Проверка допустимости значения в Кельвинах (не ниже абсолютного нуля)."""
        return kelvin >= 0

    @staticmethod
    def describe_temperature(celsius: float) -> str:
        """Описание температуры на основе значения в Цельсиях."""
        if celsius < 0:
            return "Мороз"
        elif celsius < 15:
            return "Холодно"
        elif celsius < 25:
            return "Комфортно"
        elif celsius < 35:
            return "Тепло"
        else:
            return "Жара"


# ── Вызов через имя класса (без создания объекта) ──────────────────────────

temp_c = 100.0
temp_f = TemperatureConverter.celsius_to_fahrenheit(temp_c)
temp_k = TemperatureConverter.celsius_to_kelvin(temp_c)

print(f"{temp_c}°C = {temp_f}°F")           # 100.0°C = 212.0°F
print(f"{temp_c}°C = {temp_k} K")           # 100.0°C = 373.15 K

print(TemperatureConverter.fahrenheit_to_celsius(32))   # 0.0
print(TemperatureConverter.kelvin_to_celsius(0))        # -273.15

# ── Валидация ───────────────────────────────────────────────────────────────

print(TemperatureConverter.is_valid_kelvin(300))   # True
print(TemperatureConverter.is_valid_kelvin(-5))    # False

# ── Описание температуры ────────────────────────────────────────────────────

for t in [-10, 10, 22, 30, 40]:
    desc = TemperatureConverter.describe_temperature(t)
    print(f"{t}°C — {desc}")

# ── Вызов через экземпляр (работает, но не рекомендуется) ──────────────────

converter = TemperatureConverter()
print(converter.celsius_to_fahrenheit(0))   # 32.0
```
