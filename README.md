## Краткое описание

Класс — это пользовательский тип данных, который объединяет состояние объекта и поведение объекта.  
Состояние обычно хранится в атрибутах, а поведение описывается методами.

В Python класс создаётся с помощью ключевого слова `class`.  
Создание нового класса фактически создаёт новый тип объекта, на основе которого можно создавать экземпляры. Экземпляры класса могут иметь собственные атрибуты, а методы класса могут работать с состоянием конкретного экземпляра.
